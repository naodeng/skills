# Skills

This repository contains reusable Codex Skills for creating structured,
repeatable workflows.

[中文](README.md) | [English](README_EN.md)

## Available Skills

### 30 Days Learning Plan Project Creator

[`30-days-learning-plan-project-creator/`](30-days-learning-plan-project-creator/)

Create Markdown-first 30-day learning-plan repositories with bilingual
documentation, 30 daily lesson files, a generated static course site, build
and content validation, and GitHub Pages deployment configuration.

Read the [Skill instructions](30-days-learning-plan-project-creator/SKILL.md)
for the complete workflow and validation requirements.

### Dual Repository Release

[`dual-repository-release/`](dual-repository-release/)

Verify or deliver one version across a project/fork and upstream repository,
with independent evidence for the target branch, annotated tag, GitHub Release,
and CI. A readiness review does not authorize a release.

Read the [Skill instructions](dual-repository-release/SKILL.md) for the
complete workflow and verification requirements.

### Version DoD Evidence

[`version-dod-evidence/`](version-dod-evidence/)

Build an evidence matrix from explicit acceptance criteria, separating tests,
evals, real execution, CI, and release state so partial validation is not
reported as complete.

Read the [Skill instructions](version-dod-evidence/SKILL.md) for the complete
workflow and verification requirements.

### Codex Thread Title Normalizer

[`codex-thread-title-normalizer/`](codex-thread-title-normalizer/)

Normalize Codex conversation titles in bulk using `createdAt` in the
Asia/Shanghai time zone, with a confirmation table before any rename. It never
changes projects or conversation content.

Read the [Skill instructions](codex-thread-title-normalizer/SKILL.md) for the
complete workflow and verification requirements.

### AI QA Weekly

[`ai-qa-weekly/`](ai-qa-weekly/)

Discover, verify, filter, and summarize meaningful developments at the
intersection of AI and software testing or quality engineering as a bilingual
weekly digest. The package includes a topic taxonomy, source and search
strategy, output template, and manual relevance cases.

Read the [Skill instructions](ai-qa-weekly/SKILL.md) for the complete workflow
and evidence rules.

## Repository layout

Each Skill lives in its own directory and may include its main `SKILL.md`,
agent metadata, references, examples, or supporting assets.
